# Day 02 - Classic Game

Minimal Streamlit Tic-Tac-Toe implementation.

## Run locally

```bash
cd apps/day-02-classic-game
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## One-click launch on macOS

From repo root, double-click [run-day-02-classic-game.command](/Users/abellotta/Documents/New%20project/launchers/run-day-02-classic-game.command).
